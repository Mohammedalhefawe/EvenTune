# :sparkles::sparkles: EvenTune
User Features:
Explore Public Events: Users can browse and explore all public events.
Search Events: Users can search for any public event by various properties.
Create Events: Users can create both public and private events.
View Attendees: Users can see the list of attendees for their created events.
Social Media Sharing: Users can share their events on social media platforms.
Book Events and Purchase Tickets: Users can book events and buy tickets directly through the app.
Event Promotion: Users can promote their events using pre-made promotional plans.
Event Preparation: Users can prepare for events directly through the app.
Join Event Discussions: Users can participate in discussions related to events.
Manage Reservations: Users can view, accept, or reject pending reservations and provide reasons for rejection if needed.
Venue Management: Users can take venues offline in case of any issues.
Admin Features:
Manage Users: Admins can view all registered users.
Manage Event Venues: Admins can add, remove, and update event venues.
Send Event Updates: Admins can send updates to users about any event.
Manage Preparation Stores: Admins can add, remove, and update preparation stores.
Monitor and Analyze: Admins can view statistics and monitor the overall flow of the application.
